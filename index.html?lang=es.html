2. Información que recopilamos

Nuestro objetivo es recopilar únicamente la información necesaria para operar el sitio web y comunicarnos con los visitantes.

Formulario de contacto

Cuando utilizas nuestro formulario de contacto, podemos tratar la información incluida en tu mensaje.

El formulario no requiere intencionadamente que proporciones tu nombre, número de teléfono u otros datos personales.

La información que incluyas voluntariamente en tu mensaje puede utilizarse únicamente para responder a tu consulta.

Información técnica

El sitio web puede procesar automáticamente determinada información técnica cuando lo visitas, como información necesaria para la seguridad, el funcionamiento y la entrega del sitio web.

No utilizamos intencionadamente el sitio web para crear perfiles individuales de visitantes.

3. Google Analytics

Utilizamos Google Analytics mediante Google Site Kit para comprender cómo utilizan los visitantes nuestro sitio web.

Google Analytics puede recopilar información como las páginas visitadas, ubicación aproximada, dispositivo y navegador, interacciones con el sitio web e información sobre cómo los visitantes llegaron al sitio.

Las cookies de análisis son opcionales y solo se activan cuando se ha proporcionado el consentimiento requerido mediante nuestro mecanismo de consentimiento de cookies.

Puedes rechazar o retirar tu consentimiento para las cookies de análisis mediante las preferencias de cookies disponibles en este sitio web.

Google procesa los datos de acuerdo con sus propias políticas de privacidad y condiciones.

4. Cloudflare

Utilizamos Cloudflare para DNS, proxy, rendimiento y seguridad.

Cloudflare puede procesar información técnica, como direcciones IP e información de conexión, para proporcionar estos servicios y proteger el sitio web frente a tráfico malicioso.

8Core no utiliza Cloudflare para publicidad ni para elaborar perfiles de comportamiento.

5. WhatsApp

Puedes contactar con 8Core mediante WhatsApp.

Cuando decides contactar con nosotros mediante WhatsApp, tu interacción está sujeta a la política de privacidad y las condiciones de WhatsApp.

No controlamos la información recopilada o procesada por WhatsApp.

6. Cómo utilizamos la información

La información proporcionada voluntariamente a través del sitio web puede utilizarse para responder a consultas, comunicarnos con los visitantes, proporcionar información sobre nuestros servicios, mantener y proteger el sitio web, comprender el uso del sitio mediante análisis cuando se haya proporcionado consentimiento y cumplir las obligaciones legales aplicables.

No vendemos información personal a terceros.

7. Base jurídica

Dependiendo de las circunstancias, los datos personales pueden tratarse sobre la base de tu consentimiento, la adopción de medidas a petición tuya antes de establecer una posible relación de prestación de servicios, nuestros intereses legítimos cuando corresponda o el cumplimiento de obligaciones legales.

Puedes retirar tu consentimiento en cualquier momento cuando el tratamiento se base en el consentimiento.

8. Conservación de datos

Conservamos la información personal únicamente durante el tiempo razonablemente necesario para la finalidad para la que fue recopilada, salvo que la ley exija un período de conservación más largo.

Los mensajes enviados mediante el formulario de contacto pueden conservarse durante el tiempo razonablemente necesario para responder a la consulta y mantener la comunicación correspondiente.

9. Servicios de terceros

El sitio web puede utilizar servicios de terceros, incluidos Google Analytics / Google Site Kit, Cloudflare y WhatsApp.

Estos proveedores pueden procesar información de acuerdo con sus propias políticas de privacidad.

10. Transferencias internacionales de datos

Algunos proveedores de servicios externos pueden procesar información fuera del Espacio Económico Europeo.

Cuando corresponda, dichas transferencias se realizarán utilizando las garantías adecuadas exigidas por la legislación aplicable en materia de protección de datos.

11. Tus derechos
